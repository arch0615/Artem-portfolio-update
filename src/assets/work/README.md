# Project screenshots

Real screenshots of finished applications for the Skills section, where each skill area shows the
projects that demonstrate it. Save each file here under the name below (`.webp`, `.png`, `.jpg` or
`.avif`); it appears automatically on the next build or dev reload. Until a file exists, its frame
shows a "Screenshot coming soon" placeholder.

Only real application screens belong here: no mockups, illustrations or generated images.

The whole screenshot is always shown, never cropped or stretched. Recommended sizes (WebP, under
~250 KB each):

- **phone:** a full portrait screen, e.g. 1080 × 2340 px (9:19.5)
- **browser:** the browser window's content, 1600 × 1000 px (16:10) or 1920 × 1080 px (16:9)

Remove anything you'd rather not show publicly (real names, email addresses, customer data) before
exporting. To add, rename or reorder screens, edit `src/data/project-screens.ts`; to change which
projects appear under each skill area, edit `src/data/skills.ts`.
